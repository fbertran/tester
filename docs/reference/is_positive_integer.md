# Is positive integer

Test if is a positive integer

## Usage

``` r
is_positive_integer(x)
```

## Arguments

- x:

  an R object

## Examples

``` r
is_positive_integer(1) # TRUE
#> [1] TRUE
is_positive_integer(0) # FALSE
#> [1] FALSE
is_positive_integer(pi) # FALSE
#> [1] FALSE
is_positive_integer(2.2) # FALSE
#> [1] FALSE
is_positive_integer(-1) # FALSE
#> [1] FALSE
```
