# Is negative integer

Test if is a positive integer

## Usage

``` r
is_negative_integer(x)
```

## Arguments

- x:

  an R object

## Examples

``` r
is_negative_integer(-1) # TRUE
#> [1] TRUE
is_negative_integer(1) # FALSE
#> [1] FALSE
is_negative_integer(0) # FALSE
#> [1] FALSE
is_negative_integer(pi) # FALSE
#> [1] FALSE
is_negative_integer(2.2) # FALSE
#> [1] FALSE
```
